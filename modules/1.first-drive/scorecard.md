# Scorecard — Module 1 (`first-drive`)

**The whole arc, leniently.** This is the exemplar module, so the scorecard spans **all five**
dimensions at once — but the bar is
*breadth, not depth*: the coach checks that **every beat happened**, not that any was masterful. Each
dimension `solid` / `partial` / `missing`. Pass bar: every dimension *attempted*, **≥ 3/5 solid**,
plus a cold-recall answer about the arc. Weak dimensions are logged as "keep drilling" → they're
exactly the modules to lean into next.

| # | Dimension | What `solid` looks like *here* (lenient) |
|---|---|---|
| 1 | **Planned before acting** | Explored read-only first; made the plan-or-act call consciously. |
| 2 | **Engineered context** | Pointed the agent at the right file(s), not the whole repo. |
| 3 | **Delegated & isolated well** | `attempted` = recognized this solo task needed no subagent and said so. |
| 4 | **Closed a verify loop** ⭐ | Set a runnable signal *before* coding; watched it go red→green; didn't hand-test. |
| 5 | **Reviewed & stayed the executor** | Read the diff; clean git; you decided it ships. |
