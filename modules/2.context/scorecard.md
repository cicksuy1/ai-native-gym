# Scorecard — Module 2 (`context`)

The coach grades **how you managed the context window**, not whether the code works. Five dimensions,
each `solid` / `partial` / `missing`. Pass bar: every dimension *attempted*, **≥ 3/5 solid**, plus a
cold-recall answer. Weak dimensions are logged as "keep drilling" — they never block the pass.

Emphasis this module: **Engineered context** (the whole point).

| # | Dimension | What `solid` looks like *here* |
|---|---|---|
| 1 | **Planned before acting** | Decided how to scope each task's context before diving in. |
| 2 | **Engineered context** ⭐ | `/clear`ed between unrelated tasks; fed the right files (or just-in-time retrieval), not a dump; steered any `/compact` with an explicit focus; reasoned about the memory layer. |
| 3 | **Delegated & isolated well** | `attempted` = recognized whether a subagent's fresh window would have helped offload a side-task, and said why or why not. |
| 4 | **Closed a verify loop** | Confirmed each task actually worked, not just "looked done." |
| 5 | **Reviewed & stayed the executor** | Reviewed each diff knowingly; didn't let a sprawling conversation drive the wrong file. |
