# Scorecard — Module 10 (`parallel`)

The coach grades **your isolation discipline and parallel-vs-single judgment**, not the tasks
themselves. Five dimensions, each `solid` / `partial` / `missing`. Pass bar: every dimension
*attempted*, **≥ 3/5 solid**, plus a cold-recall answer. Weak dimensions are logged as "keep
drilling".

Emphasis this module: **Delegated & isolated well** (the whole point). **Dimension 4 (Closed a verify
loop) is required-solid to pass** — you must verify each parallel result independently before merging.

| # | Dimension | What `solid` looks like *here* |
|---|---|---|
| 1 | **Planned before acting** | Judged parallel-vs-single correctly; identified independence vs. coupling before launching. |
| 2 | **Engineered context** | Each isolated worker kept its own clean context; no cross-contamination of the main window. |
| 3 | **Delegated & isolated well** ⭐ | Each parallel worker ran in its own worktree; no shared-file conflicts; recognized the coupled task that should stay single-session. |
| 4 | **Closed a verify loop** (required-solid) | Verified each parallel result independently before merging. |
| 5 | **Reviewed & stayed the executor** | Reviewed each branch/PR on its own merits; decided merge order; clean state throughout. |
