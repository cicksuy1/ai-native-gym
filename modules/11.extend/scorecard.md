# Scorecard — Module 11 (`extend`)

The coach grades **whether you matched the mechanism to the need**, not the integration itself. Five
dimensions, each `solid` / `partial` / `missing`. Pass bar: every dimension *attempted*, **≥ 3/5
solid**, plus a cold-recall answer. Weak dimensions are logged as "keep drilling".

Emphasis this module: **Reviewed & stayed the executor** (deliberate mechanism choice) and
**Engineered context** (respecting each extension's context cost). **Dimension 4 (Closed a verify
loop) is required-solid to pass** — you must show the extension actually fired, not just configured.

| # | Dimension | What `solid` looks like *here* |
|---|---|---|
| 1 | **Planned before acting** | Diagnosed the *nature* of the need (guarantee / workflow / external state) before picking a tool. |
| 2 | **Engineered context** ⭐ | Respected context cost — used on-demand skills over CLAUDE.md bloat; didn't over-add MCP servers. |
| 3 | **Delegated & isolated well** | `attempted` = considered whether the extension belongs in a subagent's context vs. the main one. |
| 4 | **Closed a verify loop** (required-solid) | Confirmed the mechanism actually fired (hook fires/blocks; skill triggers; MCP connects) — showed evidence, not just config. |
| 5 | **Reviewed & stayed the executor** ⭐ | Chose the mechanism by nature, not habit; used a **hook** where a guarantee was needed (not a CLAUDE.md hope). |
