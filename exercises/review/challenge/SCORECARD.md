# Scorecard — Module 6 (`review`)

The coach grades **how you reviewed and stayed in command**, not whether the feature works. Five
dimensions, each `solid` / `partial` / `missing`. Pass bar: every dimension *attempted*, **≥ 3/5
solid**, plus a cold-recall answer. Weak dimensions are logged as "keep drilling".

Emphasis this module: **Reviewed & stayed the executor** (the whole point).

| # | Dimension | What `solid` looks like *here* |
|---|---|---|
| 1 | **Planned before acting** | Scoped what "to ~80%" meant and what review would check before letting it run. |
| 2 | **Engineered context** | Gave the reviewer the diff + criteria *cold* (fresh context), not the writer's reasoning. |
| 3 | **Delegated & isolated well** | Used a genuine separate reviewer (subagent / cleared session) that didn't write the code. |
| 4 | **Closed a verify loop** | Tests/checks ran; review confirmed the result beyond what green proved. |
| 5 | **Reviewed & stayed the executor** ⭐ | Clean git + checkpoint; read the diff with judgment; refined; turned a mistake into a CLAUDE.md rule; *you* decided what merged. |
